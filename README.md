# 🚀 Add Campaign For Public User (Noksha Lab)

নকশা ল্যাবের সাধারণ পাবলিক গ্রাহকদের জন্য সেলফ-সার্ভিস অনলাইন অ্যাড ক্যাম্পেইন (Facebook, Instagram, Google Ads, YouTube, TikTok) অর্ডার পোর্টাল।

---

## ⚡ ১. প্রজেক্ট চালু করার নিয়ম (How to Open / Run)

এই প্রজেক্টটি দুটি ভিন্ন মোডে চালু করার জন্য দুটি সিস্টেম ব্যাচ (`.bat`) ফাইল রয়েছে:

1. **শুধুমাত্র লোকালহোস্টে (PC Only - Localhost):**
   - `start_localhost.bat` ফাইলটিতে ডাবল-ক্লিক করুন।
   - এটি শুধুমাত্র আপনার কম্পিউটারে `http://localhost:8088/` ঠিকানায় চালু হবে।

2. **লোকাল নেটওয়ার্ক / ওয়াইফাইতে (Local Network / Wi-Fi):**
   - `start_local_network.bat` ফাইলটিতে ডাবল-ক্লিক করুন।
   - এটি স্বয়ংক্রিয়ভাবে আপনার পিসির Local IPv4 খুঁজে বের করবে এবং `http://<LOCAL_IP>:8088/` ঠিকানায় চালু করবে, যাতে একই ওয়াইফাই বা ল্যানে থাকা মোবাইল ও অন্যান্য পিসি থেকেও ব্যবহার করা যায়।

3. **গিটহাব পেজেস লাইভ পোর্টাল (GitHub Pages Live):**
   - **লাইভ লিংক:** `https://mizentia.github.io/Add_Campaign_For_Public_User/`
   - গিটহাব পেজেস থেকেও লোগো, কারেন্সি রেট, অর্ডার সাবমিট এবং অর্ডার স্ট্যাটাস স্বয়ংক্রিয়ভাবে ক্লাউড ও Firebase Firestore-এর সাথে সিঙ্ক হয়।

---

## 📤 ২. গিটহাবে পুশ ও পেজ আপডেট করার নিয়ম (GitHub Push & Pages)

- **রিপোজিটরি:** `https://github.com/Mizentia/Add_Campaign_For_Public_User.git`
- যেকোনো পরিবর্তনের পর **`push_to_github.bat`** ফাইলটিতে ডাবল-ক্লিক করুন।
- এটি স্বয়ংক্রিয়ভাবে প্রজেক্টের রুলস (১০০ লাইন সীমা ও সিনট্যাক্স) যাচাই করবে, ফাইল স্টেজ করবে, কমিট মেসেজ নিবে এবং গিটহাবের `main` ব্রাঞ্চে পুশ করবে (যার ফলে GitHub Pages স্বয়ংক্রিয়ভাবে আপডেট হয়ে যাবে)।

## 📏 ৩. প্রজেক্ট রুলস মেইনটেইন করার নির্দেশনা (Rule Maintenance)

সমস্ত নীতিমালা [`PROJECT_RULES.md`](./PROJECT_RULES.md) ফাইলে বিস্তারিত দেওয়া আছে। কোড পরিবর্তনের পর রুলস ঠিক আছে কিনা যাচাই করতে টার্মিনালে চালান:

```bash
npm run verify
```

অথবা আলাদাভাবে:
- **১০০-লাইন কোড অডিট:** `node scripts/audit-line-counts.js`
- **জাভাস্ক্রিপ্ট সিনট্যাক্স যাচাই:** `node scripts/verify-syntax.js`

> **সতর্কতা:** প্রতিটি ফাইল অবশ্যই **সর্বোচ্চ ১০০ লাইন বা তার নিচে** রাখতে হবে এবং `data/` ফোল্ডারের গ্রাহক তথ্য গিটহাবে পুশ করা যাবে না।
